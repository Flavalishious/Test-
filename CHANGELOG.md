# Changelog

## [1.0.0] - 2024-01-01

### Initial Release

#### Features
- ✨ Full Framer integration with property controls
- ✨ Dual mode support (testing with API key, production with Cloudflare Worker)
- ✨ Multiple AI model support (GPT-4o, GPT-4o-mini, GPT-4-turbo, GPT-3.5-turbo)
- ✨ Built-in lead generation with email capture
- ✨ Fully customizable UI through Framer sidebar
- ✨ Custom system instructions for AI behavior
- ✨ Responsive design for mobile and desktop
- ✨ Real-time chat interface with smooth scrolling
- ✨ Loading states and error handling
- ✨ Cloudflare Worker proxy for secure production deployment
- ✨ Lead capture webhook integration
- ✨ Optional D1 database support for lead storage

#### Documentation
- 📚 Comprehensive README with setup instructions
- 📚 Quick setup guide for customers
- 📚 Selling tips and marketing strategies
- 📚 Cloudflare Worker deployment guide

- 🎨 Typography controls (font size, family)

## How to Update

### For Developers
1. Pull latest changes from GitHub
2. Update `AIChat.tsx` in your Framer project
3. Redeploy Cloudflare Worker if changes to `cloudflare-worker.js`

### For Customers
1. Re-copy `AIChat.tsx` into your Framer project
2. Your customizations in Framer sidebar will be preserved
3. Check CHANGELOG for any breaking changes
